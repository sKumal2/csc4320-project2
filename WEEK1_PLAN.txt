DAY 3 - Understand the workload by hand      (~1.5 h)

      table) once you have the seed - just jobs/producers/consumers/capacity.

DAY 4 - Invariants                           (~1 h)
  Write them in your own words. Things the PDF expects you to cover:
  [ ] occupancy bounds (0 <= occupancy <= capacity)
  [ ] occupancy == number of records actually in the queue (incl. STOP)
  [ ] FIFO: dequeue order == enqueue order
  [ ] exactly-once: each real job ENQ once, DEQ once, DONE once
  [ ] wait predicates: consumer waits while empty, producer while full
  [ ] STOP rules: one per consumer, only after all real ENQs, consumer exits
      after STOP_GET
  [ ] which data the queue mutex protects, and what must stay OUTSIDE it
      (processing / delay)

DAY 5 - Six-event hand trace                 (~1 h)
  [ ] Use the public case (seed=7, jobs=6, P=2, C=2, capacity=2, delay=0)
  [ ] Write 6 rows in the real CSV format:
        seq,actor,event,job_id,occupancy,result
      Events: ENQ, DEQ, DONE (STOP_ENQ/STOP_GET later). DONE has the result,
      everything else uses "-".
  [ ] Make it legal: occupancy never > 2, DEQ takes the head, DONE comes
      after that consumer's DEQ, correct result value from Day 3.
  [ ] Bonus understanding: include one moment where the queue is full and
      say in a note which thread would block.

DAY 6 - One-page design                      (~2 h)
  Keep to ONE page. Suggested sections:
  [ ] Language, compiler, seed
  [ ] Program structure: modes (race / cv / sem), files you plan
      (src/, checker/), how config + mode=cv|sem are read
  [ ] Queue design: data structure (your own bounded FIFO, not a blocking
      queue library), put/get operations, mutex + not_empty/not_full;
      semaphore version: empty=capacity, full=0, mutex
  [ ] Thread lifecycle: start consumers+producers, main joins producers,
      inserts STOP1..STOPC, joins consumers, then summary
  [ ] Race experiment idea: how your gates/barrier force both reads first
  [ ] Trace + checker plan (one paragraph)
  [ ] Invariants (from Day 4) - can be bulleted or an attached half page
